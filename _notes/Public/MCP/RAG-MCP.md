# [Source: RAG-MCP: Mitigating Prompt Bloat in LLM Tool Selection via Retrieval-Augmented Generation](https://arxiv.org/abs/2505.03275)

## TLDR;
- ใช้การค้นหาตามความหมาย (semantic retrieval) คัดเลือกเครื่องมือ MCP ที่เกี่ยวข้องก่อนส่งให้ LLM เพื่อลดความยาวของ prompt และช่วยให้เลือกเครื่องมือได้ง่ายขึ้น
- ลดโทเคนใน prompt ได้เกิน 50% และเพิ่มความแม่นยำในการเลือกเครื่องมือกว่า 3 เท่า (43.13% เทียบกับ 13.62% ของวิธีฐาน)
- ช่วยให้ LLM เลือกเครื่องมือได้แม่นยำขึ้นแม้เชื่อมต่อเครื่องมือจำนวนมาก

## 1.Introduction
- Problem
  - LLM มีข้อจำกัดด้านความรู้ในพารามิเตอร์และความยาวบริบท จึงต้องใช้ฟังก์ชันหรือเครื่องมือภายนอก เช่น web search ฐานข้อมูล และเครื่องคิดเลข
  - แม้ ReAct, Toolformer และ Gorilla จะช่วยให้ใช้เครื่องมือได้ดีขึ้น แต่เมื่อมีเครื่องมือจำนวนมากจะเกิดปัญหา:
    - Prompt bloat: ต้องใส่คำอธิบายเครื่องมือจำนวนมากลงในบริบท
    - Decision overhead: โมเดลเลือกเครื่องมือที่ถูกต้องได้ยากขึ้น และอาจสร้างชื่อ API หรือพารามิเตอร์ที่ไม่มีอยู่จริง
- Hypothesis
  - แยกการค้นหาเครื่องมือออกจากการสร้างคำตอบ โดยใช้ RAG ค้นหาตามความหมายและเลือกเฉพาะเครื่องมือที่น่าจะเกี่ยวข้องมาให้ LLM

![Tools_w_wo_MCP](/assets/img/Other/LLM/RAG-MCP.avif)

### Contributions
- สถาปัตยกรรม RAG-MCP: ผสาน retrieval กับการเรียกใช้ฟังก์ชันในบริบท MCP
- Semantic tool retrieval: สร้างดัชนีคำอธิบายและสคีมาของเครื่องมือ แล้วเทียบกับโจทย์ผู้ใช้เพื่อเลือก top-k ช่วยลดบริบทและภาระในการตัดสินใจ
- ผลลัพธ์ดีกว่าวิธีฐาน: รักษาความแม่นยำในการเลือกเครื่องมือเมื่อจำนวนเครื่องมือเพิ่มขึ้น และลดการเลือกเครื่องมือหรือพารามิเตอร์ผิด

## 2.Methodology
ศึกษาว่าจำนวนเซิร์ฟเวอร์ MCP และคำอธิบายเครื่องมือที่เพิ่มขึ้นใน prompt ส่งผลต่อการเลือกและเรียกใช้เครื่องมือของ LLM อย่างไร

### Prompt Bloat & MCP Stress Test
#### How
- ดัดแปลงการทดสอบจากแนวคิด Needle-in-a-Haystack (NIAH หรือการงมเข็มในมหาสมุทร) เพื่อดูว่าโมเดลหาข้อมูลที่ถูกต้องจากบริบทยาวได้หรือไม่ โดยสุ่มเลือก MCP ที่ถูกต้อง 1 ตัวร่วมกับตัวลวง N−1 ตัว (N ตั้งแต่ 1 - 11100) แล้วให้โมเดลเลือกและเรียกใช้ WebSearch MCP วัดทั้งการเลือกเครื่องมือและการทำงานจนได้คำตอบ
- ใช้เซิร์ฟเวอร์ MCP สาธารณะมากกว่า 4400 ตัว เพื่อจำลองระบบที่มีเครื่องมือให้เลือกจำนวนมาก

#### Matrix
- Choose the right Tool = 1
- Wrong Tools = 0

### RAG-MCP
#### How
- ต่อยอดจาก Prompt Bloat & MCP Stress Test
- สำหรับแต่ละค่า N โมเดลต้องทำงานค้นเว็บ 20 งาน โดยแต่ละงานต้อง (a) เลือก MCP ที่ถูกต้อง (b) สร้าง query/คำตอบตามรูปแบบ และ (c) ส่งผลลัพธ์สุดท้ายกลับมา
- เปรียบเทียบ 3 วิธี ได้แก่ Blank Conditioning, Actual Match และ RAG-MCP ซึ่งจัดอันดับตามความหมายแล้วใส่เฉพาะสคีมาของเครื่องมือที่เหมาะสมที่สุดลงใน prompt

#### Matrix
- Accuracy = สัดส่วนรอบที่เลือก MCP เป้าหมายได้ถูกต้อง
- Avg Prompt Tokens = จำนวนโทเคนเฉลี่ยใน prompt รวม metadata และสคีมาของเครื่องมือ
- Avg Completion Tokens = จำนวนโทเคนเฉลี่ยในคำตอบที่โมเดลสร้าง
- Latency = เวลาที่ใช้ในการตอบ
- Llama-based judge = ใช้โมเดล Llama ตรวจผลลัพธ์สุดท้ายเทียบกับคำตอบอ้างอิง (ground truth) เพื่อตัดสินผลโดยอัตโนมัติ

#### Baselines
- Blank Conditioning: ใส่สคีมาของ MCP ทั้ง N ตัวให้โมเดลเลือกเอง
- Actual Match: กรองด้วยคีย์เวิร์ดเบื้องต้นก่อนให้โมเดลเลือก
- RAG-MCP: จัดอันดับตามความหมายจากดัชนีเวกเตอร์ แล้วใส่เฉพาะสคีมาของเครื่องมือที่เหมาะสมที่สุดลงใน prompt

## 3.Experiment Result
### 3.1 Experiment Choose the right tool
![Tools_w_wo_MCP](/assets/img/Other/LLM/RAG_MCP_result.avif)

- แกน X (MCP Number): จำนวนเครื่องมือ (N) ในแต่ละรอบทดสอบ แต่ละคอลัมน์แทนค่า N ที่ต่างกัน ตั้งแต่หลักหน่วยถึงหลักหมื่น (≈1 → 11,100)
- แกน Y (Key MCP Position): ตำแหน่งของเครื่องมือที่ถูกต้องในรายการเครื่องมือที่ให้โมเดลเลือก
- สี: อ้างอิงสเกลด้านขวา
  - เหลือง = 1.0 = สำเร็จ (เลือก/เรียกใช้เครื่องมือที่ถูกต้องได้)
  - ม่วง = 0.0 = ล้มเหลว (เลือกผิดหรือไม่สำเร็จ)

## 4.Conclusion
- ผลทดสอบแสดงว่าความสำเร็จลดลงเมื่อจำนวนเครื่องมือเพิ่มขึ้น โดยตารางสีเหลือง–ม่วงแสดงช่วงที่ยังเลือกเครื่องมือได้สำเร็จ
- เมื่อมีเครื่องมือ <=30 ตัว อัตราความสำเร็จยังสูงมาก
- ในการทดสอบนี้ เมื่อมีเครื่องมือมากกว่า 100 ตัว โมเดลแทบทำงานไม่สำเร็จ
- เหตุผลที่ RAG-MCP เหนือกว่า
  - Focused context filtering: เลือกเฉพาะบริบทที่เกี่ยวข้อง
  - Prompt efficiency: ใช้โทเคนใน prompt ได้คุ้มค่าขึ้น
  - Balanced generation: ใช้โทเคนคำตอบเพิ่มขึ้นเล็กน้อยเพื่อให้ตรวจสอบและให้เหตุผลได้ดีขึ้น
