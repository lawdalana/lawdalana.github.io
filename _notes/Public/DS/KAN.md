# [KAN: Kolmogorov-Arnold Networks สู่การปฏิวัติ Deep Learning](https://arxiv.org/abs/2404.19756)

![KAN01](/assets/img/Other/DS/KAN01.avif)

> **KAN เสนอทางเลือกให้ MLP ด้วยฟังก์ชันบนเส้นเชื่อมที่เรียนรู้และตีความได้ เหมาะกับการศึกษาความสัมพันธ์ทางวิทยาศาสตร์อย่างไร?**

---

Multi-Layer Perceptrons (MLPs) เป็นรากฐานสำคัญของสถาปัตยกรรม Deep Learning โดยมี Universal Approximation Theorem (UAT) รองรับความสามารถในการประมาณฟังก์ชัน แม้ MLPs จะใช้แก้ปัญหาได้หลากหลาย แต่ยังมีความท้าทายสองด้านคือ **การตีความการทำงานของโมเดล (Interpretability)** และ **ปัญหาคำสาปแห่งมิติ (Curse of Dimensionality)**

**Kolmogorov-Arnold Networks (KANs)** เสนอวิธีจัดโครงสร้างเครือข่ายอีกแบบ โดยนำแนวคิดทางคณิตศาสตร์มาเปลี่ยนบทบาทของโหนดและเส้นเชื่อม

---

## 🔄 1. การเปลี่ยนกระบวนทัศน์: สลับขั้วโหนดและเส้นเชื่อม

![KAN02](/assets/img/Other/DS/KAN02.avif)

ใน MLP แบบเดิม เราใช้ฟังก์ชันกระตุ้นที่มีรูปแบบตายตัว เช่น ReLU ที่ **โหนด (Nodes)** และใช้ค่าน้ำหนักเชิงเส้น (Linear Weights) บนเส้นเชื่อม

KAN เปลี่ยนตำแหน่งของฟังก์ชันที่เรียนรู้ได้:

KAN ใช้ **ฟังก์ชันตัวแปรเดียวที่เรียนรู้ได้ (Univariate Functions)** ซึ่งสร้างจาก B-splines บน **เส้นเชื่อม (Edges)** ส่วนโหนดทำหน้าที่รวมค่าที่ได้รับ

การแยกโครงสร้างกราฟของเครือข่าย (External Degree of Freedom) ออกจากฟังก์ชันบนเส้นเชื่อม (Internal Degree of Freedom) ช่วยให้ตรวจดูการทำงานภายในของ KAN ได้ จึงเป็นแนวทางหนึ่งในการจัดการข้อจำกัดด้านการตีความ

> 🎥 **ดูภาพเคลื่อนไหว KAN ทำงาน:** [How KAN Works — YouTube](https://youtu.be/myFtp5zMv8U?si=RCf5jIZerFKlrCpk)

## ➰ 2. เจาะลึกกลไก [B-spline: เส้นโค้งแห่งการเรียนรู้](https://www.youtube.com/watch?v=203v61y2o1M)

![KAN03](/assets/img/Other/DS/KAN03.avif)

กลไกสำคัญของ KAN คือ **B-spline (Basis Spline)** ซึ่งใช้สร้างฟังก์ชันที่เรียนรู้ได้บนเส้นเชื่อม

**B-spline คืออะไร?**

B-spline ใช้สร้างเส้นโค้งจากกลุ่ม **จุดควบคุม (Control Points)** จุดเด่นคือ **Local Control (การควบคุมแบบเฉพาะที่)** เมื่อขยับจุดควบคุมจุดหนึ่ง จะมีผลเฉพาะช่วงของเส้นโค้งที่จุดนั้นควบคุม โดยไม่เปลี่ยนเส้นโค้งทั้งหมด

**องค์ประกอบหลักของ B-spline**

- **Control Points ($P_i$):** จุดที่กำหนดรูปร่างของเส้นโค้ง ยิ่งมีจุดมากก็ยิ่งปรับรายละเอียดได้มากขึ้น
- **Degree ($p$):** ระดับของพหุนามที่ใช้สร้างเส้นโค้ง ซึ่งเกี่ยวข้องกับความเรียบของเส้นโค้ง (มักกำหนดไว้ที่ $p=3$)
- **Knot Vector ($T$):** ชุดตัวเลขที่กำหนดช่วงอิทธิพลของแต่ละ Control Point จำนวน knots คำนวณได้จาก $( \text{จำนวนจุดควบคุม} ) + p + 1$

**สมการที่ซ่อนอยู่เบื้องหลัง: Cox-de Boor formula**

สมการนี้ใช้คำนวณน้ำหนักของ Control Point แต่ละจุดที่มีต่อตำแหน่งบนเส้นโค้ง ณ ค่าพารามิเตอร์ $t$ (Univariate Parameter):
$$ N_{i,0}(t) = \begin{cases} 1 & \text{if } t_i \le t < t_{i+1} \\ 0 & \text{otherwise} \end{cases} $$
$$ N_{i,p}(t) = \frac{t - t_i}{t_{i+p} - t_i} N_{i,p-1}(t) + \frac{t_{i+p+1} - t}{t_{i+p+1} - t_{i+1}} N_{i+1,p-1}(t) $$

> 🎮 **ลองเล่น Interactive B-spline ได้ที่:** [B-Spline Curve with Knots — Wolfram Demonstrations](https://demonstrations.wolfram.com/BSplineCurveWithKnots/) — ขยับ Control Points และ Knot Vector แบบ real-time เพื่อดูผลต่อเส้นโค้ง
### 🧮 ตัวอย่างการคำนวณเบื้องต้น
เพื่อให้เห็นภาพชัดเจน ลองคำนวณ B-spline แบบ $p=1$ (เส้นตรง) โดยมี 3 Control Points ($P_0, P_1, P_2$) และใช้ Knot Vector $T = [0, 1, 2, 3, 4]$ 
เป้าหมายคือหาตำแหน่งบนเส้นโค้งเมื่อพารามิเตอร์ $t = 1.5$

1. **Base Case ($p=0$):** ฟังก์ชันจะให้ค่าเป็น 1 เฉพาะเมื่อ $t$ ตกอยู่ในช่วงนั้น
   เนื่องจาก $1.5$ อยู่ในช่วง $[1, 2)$ ดังนั้นมีเพียง $N_{1,0}(1.5)$ เท่านั้นที่เท่ากับ $1$ (ส่วนจุดอื่นเป็น $0$)
2. **คำนวณน้ำหนัก ($p=1$):** แทนค่า $N_{i,0}$ และ Knot Vector ลงในสมการ Cox-de Boor จะได้:
   - ค่าน้ำหนักของ $P_0 \rightarrow N_{0,1}(1.5) = 0.5$
   - ค่าน้ำหนักของ $P_1 \rightarrow N_{1,1}(1.5) = 0.5$
   - ค่าน้ำหนักของ $P_2 \rightarrow N_{2,1}(1.5) = 0$
3. **สรุปตำแหน่งเส้นโค้ง:** ตำแหน่งที่ $t=1.5$ คือ $C(1.5) = 0.5 P_0 + 0.5 P_1 + 0 P_2$
   *ในตัวอย่างนี้ จุด $P_2$ ไม่มีผลต่อตำแหน่งที่คำนวณ ซึ่งแสดงคุณสมบัติ Local Control*

### 🧠 B-spline ในมุมมอง KAN Neural Network (การอัปเดต Backprop)
ในโมเดล KAN พารามิเตอร์บนเส้นเชื่อมเปลี่ยนจากค่าน้ำหนัก (Weight) ค่าเดียวมาเป็น **Spline Coefficients ($c_i$)** ซึ่งเทียบได้กับความสูงหรือค่าแกน Y ของ Control Point
ฟังก์ชันบนเส้นเชื่อมคือ: $f(x) = \sum c_i N_{i,p}(x)$ (ค่า $x$ ทำหน้าที่เหมือนตัวแปร $t$)

**ตัวอย่างการทำงาน Backpropagation ใน KAN (เมื่อ Input $x=1.5$, เป้าหมาย Target $= 4.0$):**

- **Forward Pass:** สมมติโมเดลสุ่มค่าเริ่มต้นพารามิเตอร์มาเป็น $c_0=2.0$, $c_1=4.0$, $c_2=1.0$
  จากตัวอย่างด้านบน น้ำหนักคือ $[0.5, 0.5, 0]$
  โมเดลทายผลลัพธ์ $f(1.5) = (2.0 \times 0.5) + (4.0 \times 0.5) + (1.0 \times 0) = \mathbf{3.0}$
- **Error:** ทำนายได้ $3.0$ แต่เป้าหมายคือ $4.0$ จึงต้องปรับผลลัพธ์ให้เพิ่มขึ้นอีก $1.0$
- **Backward Pass:** เมื่อคำนวณย้อนกลับ พบว่า $c_0$ มีส่วน 50% และ $c_1$ มีส่วน 50% ***ส่วน $c_2$ ไม่มีผลต่อผลลัพธ์นี้***
  Optimizer จึง **เพิ่มค่าเฉพาะ $c_0$ และ $c_1$** เช่น ปรับเป็น $c_0=3.0, c_1=5.0$ โดย **ไม่เปลี่ยน $c_2$**
- **ผลลัพธ์ใหม่:** เมื่อคำนวณรอบใหม่ $f(1.5) = (3.0 \times 0.5) + (5.0 \times 0.5) + 0 = \mathbf{4.0}$ จึงได้ค่าตรงกับเป้าหมาย

การอัปเดตเฉพาะจุด (Local Update) ช่วยลดการคำนวณในขั้นตอนอัปเดต และไม่เปลี่ยนค่าฟังก์ชันในช่วงที่อยู่นอกอิทธิพลของจุดเหล่านั้น

## ⚔️ 3. บทพิสูจน์ในสนามจริง: MLP vs KAN

![KAN04](/assets/img/Other/DS/KAN04.avif)

ทั้งสองสถาปัตยกรรมมีความแตกต่างหลักดังนี้:

| คุณลักษณะ | Multi-Layer Perceptron (MLP) | Kolmogorov-Arnold Network (KAN) | ผลกระทบเชิงกลยุทธ์ |
| :--- | :--- | :--- | :--- |
| **รากฐานทฤษฎี** | Universal Approximation Theorem | Kolmogorov-Arnold Theorem | KAN จัดการมิติที่ซับซ้อนภายในโครงสร้างได้ดีกว่า |
| **ตำแหน่ง Activation** | โหนด (Nodes) / ฟังก์ชันตายตัว | ขอบเชื่อม (Edges) / ฟังก์ชันเรียนรู้ได้ | KAN มีความยืดหยุ่นสูง ปรับรูปฟังก์ชันได้ทุกเส้นเชื่อม |
| **พารามิเตอร์** | Linear weight matrices (ค่าน้ำหนักเชิงเส้น) | B-splines (ฟังก์ชันเส้นโค้งที่เรียนรู้ได้) | เปลี่ยนจากการเรียนรู้ค่าน้ำหนักเป็นการเรียนรู้รูปร่างฟังก์ชัน |
| **การทำงานที่โหนด** | Nonlinear activation (ซับซ้อน) | Simple summation (รวมค่าธรรมดา) | ลดความซับซ้อนที่โหนด เพิ่มความโปร่งใส |
| **การขยายสเกล** | เพิ่มความกว้าง/ลึก (ต้องเริ่มฝึกใหม่) | ขยาย Grid ของ Spline (Grid Extension) | เพิ่มความละเอียดได้โดยไม่ต้องเริ่มฝึกใหม่ |

> **Local Plasticity** หรือการเรียนรู้เฉพาะจุดของ B-splines ช่วยจำกัดผลของการอัปเดตให้อยู่ในบางช่วงของฟังก์ชัน จึงเป็นแนวทางลดการลืมความรู้เดิม (Catastrophic Forgetting) งานต้นฉบับแสดงผลนี้ในโจทย์ทดลองอย่างง่าย และยังไม่ได้รับประกันว่าจะได้ผลกับงานที่ซับซ้อนขึ้น

## 📈 4. กฎการขยายตัว (Scaling Laws) และพลังแห่งความแม่นยำ

![KAN05](/assets/img/Other/DS/KAN05.avif)

ตัวอย่างผลการทดลองที่แสดงความสามารถของ KAN ได้แก่:

- **เอาชนะ "คำสาปแห่งมิติ":** ในการแก้ปัญหาสมการ PDE (เช่น สมการ Poisson) โมเดล KAN ขนาดเล็ก (2 ชั้น กว้าง 10) ที่มีพารามิเตอร์ร้อยกว่าตัว ให้ความแม่นยำ (MSE < 0.0000001) เหนือกว่า MLP ที่ใหญ่กว่าถึงร้อยเท่า (4 ชั้น กว้าง 100)
- **กลยุทธ์ Grid Extension ("Staircase Effect"):** เริ่มฝึกด้วย grid ที่หยาบก่อน เมื่อโมเดลเรียนรู้โครงสร้างเบื้องต้นแล้วจึงเพิ่มความละเอียดของ grid เพื่อปรับความแม่นยำต่อ โดยไม่ต้องเริ่มฝึกใหม่จากศูนย์

## 🧠 5. AI Collaborator: ทลายกล่องดำ สู่คณิตศาสตร์ที่มนุษย์เข้าใจ

![KAN06](/assets/img/Other/DS/KAN06.avif)

KAN เปิดให้นักวิทยาศาสตร์ตรวจดูและปรับแต่งฟังก์ชันภายในโมเดลได้ กระบวนการนี้เรียกว่า **"Human-in-the-loop Surgery"** หรือการปรับแต่งโครงข่ายโดยมีมนุษย์ร่วมตัดสินใจ

- **Symbolification (การแปลงฟังก์ชันเป็นสมการ):** พล็อตกราฟฟังก์ชันย่อยของ KAN แล้วปรับให้ตรงกับรูปแบบคณิตศาสตร์มาตรฐาน เช่น ไซน์ ลอการิทึม หรือพหุนามได้
- **การค้นพบทางวิทยาศาสตร์:** ในตัวอย่างทฤษฎีปม (Knot Theory) KAN ทำนายผลด้วยความแม่นยำ 81.6% โดยใช้พารามิเตอร์ราว 200 ตัว เทียบกับโมเดลจาก DeepMind ที่ใช้กว่า 300,000 ตัวและได้ความแม่นยำ 78% นอกจากนี้ KAN ยังช่วยค้นหาสูตรความสัมพันธ์ทางคณิตศาสตร์แบบใหม่
- **Unsupervised Discovery:** KAN ตรวจจับความสัมพันธ์ระหว่างตัวแปรได้ ช่วยให้นักวิจัยเลือกศึกษาตัวแปรสำคัญและค้นหากฎทางฟิสิกส์ต่อ

## ⚖️ 6. บทสรุป การตัดสินใจ: งานนี้ใช้ MLP หรือ KAN?

![KAN07](/assets/img/Other/DS/KAN07.avif)

แนวทางเบื้องต้นในการเลือกใช้ MLP หรือ KAN มีดังนี้:

1. **ต้องการความแม่นยำสูงในมิติต่ำ (Low-dimensional)?** 👉 เลือก **KAN**
2. **ต้องการอธิบายผลลัพธ์ (Interpretability) และเข้าใจกลไกภายใน?** 👉 เลือก **KAN**
3. **ต้องการโมเดลขนาดเล็กสำหรับอุปกรณ์ที่มีหน่วยความจำจำกัด (Memory constraint)?** 👉 เลือก **KAN**
4. **ทำ Continual Learning และต้องการลดการลืมความรู้เก่า?** 👉 ทดลอง **KAN** โดยตรวจสอบผลกับงานจริงเพิ่มเติม
5. **ให้ความสำคัญกับความเร็วในการฝึกบนข้อมูลและโครงข่ายขนาดใหญ่?** 👉 เลือก **MLP** (ปัจจุบัน KAN ยังใช้เวลาฝึกนานกว่าถึง 10 เท่า)
